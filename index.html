Security Architecture

Encrypted Offline Learning Media Protection

Learners can securely download authorized course lecture videos for offline study without exposing static storage URLs or unencrypted files.

No Public MP4 URLs

Media access is mediated via short-lived signed tokens. No permanent S3 or Cloudinary storage URLs are rendered in source code.

AES-GCM Encryption at Rest

Offline video packages are stored in browser IndexedDB encrypted with AES-GCM (256-bit) using keys bound to the authenticated learner session and tenant.

Expiring Entitlements & DRM Ready

Offline licenses enforce TTL limits (14 days) before requiring online re-validation. The media protection interface is isolated to allow hardware DRM (EME) upgrades.
